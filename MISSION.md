# Mission · Read Zippy’s implementation

## Why

Learn how the current Zippy repository turns Ploy’s demo into working features. The initial goal is to navigate the code independently and explain where a feature’s behavior comes from.

## Success looks like

- Trace a chat message from the browser to the backend and back to a rendered card.
- Point to the code that owns a product price, a payment decision or a proactive notification.
- Use an offline test to check an explanation of the code.

## Constraints

- Keep each lesson short and make exercises runnable from source or offline tests.
