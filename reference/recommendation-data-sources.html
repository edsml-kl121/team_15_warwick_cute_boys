Recommendation data sources

MongoDB supplies recommendation context and the food catalog. Object storage supplies private images.

Which reads happen

Guest context
load_recommendation_context calls read_guest_recommendation_data by guest ID. MongoDB supplies the profile, stored persona and current day’s meals. Context loader · MongoDB queries
Food catalog
read_food_catalog reads the food_db document from the food_catalog collection. A later places request calls Shopee Food for restaurants. Catalog query · Places lookup
Item listings
The item branch derives sleep and activity signals from the guest history and calls Shopee Mall for product listings. Item branch
Catalog image
GET /food-log/catalog-image resolves the MongoDB catalog entry and redirects to a short-lived signed S3 URL when an eligible image exists. Image route · Image signing
