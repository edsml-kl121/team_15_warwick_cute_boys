# Matt Pocock’s skills for Codex

This directory contains 27 skills adapted from [Matt Pocock’s v1.3.2 release](https://github.com/mattpocock/skills/tree/v1.3.2). It includes the upstream templates, references, and [MIT license](LICENSE.mattpocock). Skills that require explicit invocation use Codex’s `agents/openai.yaml` policy.

Codex discovers the bundle directly under `.agents/skills`.

Open a fresh Codex session and type `$handoff` to select the handoff skill, or `$ask-matt` to choose a workflow. Give the handoff file path to a fresh session and ask it to read the file and continue.
