Trace the recommendation bucket

Trace which parts of a recommended meal card come from MongoDB and which come from object storage.

Follow a food card from data to image

  1. Guest context. load_recommendation_context reads the guest’s profile, health history and meals by guest ID from MongoDB. Context loader
  2. Meal catalog. The food branch calls food_catalog() to load the MongoDB document food_catalog/food_db. It chooses a dish and includes the food_id in the meal card. Catalog query
  3. Image. When the browser requests GET /food-log/catalog-image?food_id=…, the backend finds that catalog entry and redirects to a signed URL for its private S3 image. Image route · Image signing

Predict the source

Where does the agent read the rows it uses to rank meals?

Answer key

The MongoDB catalog document supplies the ranking data. The bucket serves eligible private images.
