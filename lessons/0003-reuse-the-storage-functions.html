Lesson 3 · 4 minutes

Reuse the storage functions

Pick an existing helper for a new agent that needs a guest’s recent data and a JSON catalog.

Follow the calls

  1. Separate setup from use. create_app builds the MongoDB client and the S3 adapter at startup. The normal MongoDB connection comes from MONGO_URL. A configured RECOMMENDATION_MONGO_URL supplies the agents’ separate read connection. Startup
  2. Reuse the existing context loader. Both agents call load_recommendation_context. It calls read_guest_recommendation_data for fresh data by guest ID and looks up a bucket persona when no persona is available. Agent entry point · MongoDB query
  3. Read the catalog explicitly. The food agent calls await self.data.read("body_data/food_db.json"). self.data is the configured BucketRecommendationData adapter. The read returns parsed JSON. S3 reader and catalog caller

For a regular guest update, follow put_persona. It receives the guest-scoped service, updates its state and calls zippy.store.save(). That works with MongoDB and with the local JSON store. Example route · Store selection

Choose the helper

A new agent needs the same merged context as the two presenter agents. Which function should you use?

Your handler needs the contents of a JSON object. Which method returns parsed data?

Answer key

Use load_recommendation_context for the merged guest data and BucketRecommendationData.read for a JSON object.
